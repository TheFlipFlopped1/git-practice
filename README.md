
# HelloooOooooOOO

This is an app that says hello to you.

# Running the App

To run the app, you should do this:

```sh
# on windows
python hello.py

# or possibly
py hello.py
```

```sh
# on macOS or linux distros
python3 hello.py
```

# Other Languages

To run the app in Spanish, run `hola.py` instead.
